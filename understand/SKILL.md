# Understand

目标是让对方真正读懂，不是让他看到你做了什么。整件事只产出说明，不产出改动。

## 1 定位目标

默认从会话上下文里取目标：刚改的 diff、刚读的文件、光标位置、刚讨论过的东西。取不到就问一句要讲什么，不要猜一大圈。

范围含糊时先说出你怎么理解这个范围，再往下做，对方能当场纠正。

## 2 判断规模

- 简单：单个文件、单个函数、一次 diff、一段会话记录。自己读一趟，直接写。
- 复杂：跨多文件或多个服务、整块子系统、要讲全局架构。先派 2 到 4 个 `Explore` 子代理并行（`TaskCreate` 带 `agentType: "Explore"`，再 `TaskExecute`），每个盯一个切片；等它们回来，你自己合并成一份说明。

拿不准时按简单走。只有明显跨多文件才派子代理。

## 3 收集证据

读代码本身，再读它的历史。两件事都要做，只有代码会漏掉「为什么」，只有历史会说错「现在怎么运作」。

```bash
git blame -L <start>,<end> <file>          # 这几行的最后改动
git log --follow --oneline -20 -- <file>   # 含改名的文件历史
git log --follow -p -- <file>              # 带补丁的完整历史
git log -1 --format=%B <commit>            # 完整提交信息，含 PR 号
gh pr view <number> --json title,body,author,mergedAt,closingIssuesReferences,comments,reviews
```

仓库内的 README、设计文档、ADR、代码注释也读，它们常常就是原始理由的唯一记录。

按证据强度分开表述：

- 提交信息、PR 描述、评审评论、文档原话里读到的理由：直接陈述，能引原文就引。
- 只有代码形态暗示的理由（防御性判空、重试、开关）：说清楚这是推断，以及推断依据。
- 查不到：明说「历史里没有记录」，不要编一条合理的动机。

时间跨度大时往回追，不要把最近一次提交当成设计原因，当前形态往往是多个早期决定叠出来的。

## 4 怎么讲

按这个顺序，缺哪块讲哪块：

1. 一句平实的定义。这东西在通用意义上是什么，有通用名字就用通用名字，然后落到眼前这个仓库里它干什么。这是最小完整答案，一两句，到此可以停。
2. 怎么运作。顺着真实流程走一遍：谁触发、一步步发生了什么、数据去哪、决策点在哪。点名具体的文件和函数，而不是「服务委托给客户端」这种抽象话。
3. 为什么长这样。讲第 3 步找到的理由，保留推断和未知的措辞。有取舍就讲取舍的另一面。
4. 位置图。开始动这块代码需要先读哪几个文件，一两行，不要整仓库目录树。
5. 坑。非直觉行为、历史包袱、容易踩的地方。没有就跳过。

不要做的事：不要打印「核心要点」「TL;DR」「值得慢慢看的地方」这类标签句；不要把函数和常量列一遍当解释，那是参考不是讲解；不要复述你的探索过程。

对方问的是小问题时，答案就该短。宁可停在一两层，等对方要更深。

## 5 图

三个以上活动部件时，不要一张图全画完。分步画，每张在前一张基础上加一个部件，让对方看着系统一点点长出来：

1. 第一张只画 A 到 B。
2. 重画，加上 C。
3. 再重画，加上回流边或下一块。

流程和结构用 mermaid，标签本身承载信息。位置、布局、前后对比这类空间问题用 ASCII 或直接生成图，图里标签要短，长文本会被画坏。只有一个要点时不需要图。

## 6 保持对话

先给最小完整答案，然后停下来等对方问。不要出题考对方，不要让他复述，不要「接下来这一段很重要」这种节奏表演。想强调就直接说内容，不要预告它的重要性。

一次说完没法追问的场景，结尾给一句「还想往下挖哪块」，直说。

## 7 怎么写

用中文，跟对方的语言一致。下面这些是硬要求：

- 短句。一句一到两个逗号，逗号堆起来就拆成两句。一段别超过三句。
- 不用破折号，不用弯引号，不用 emoji，标题用句子大小写。
- 一个概念定一个词，之后一直用它，不要换同义词。
- 说机制不说感觉。「命中缓存后直接返回，不打数据库」而不是「性能很友好」。
- 用主动语态，点出谁做的。「编译器校验查询」而不是「查询会被校验」。
- 给的数字和结论要具体。「快了约 40 毫秒」而不是「明显改善」。
- 禁这些词：此外、值得注意的是、深入探讨、赋能、闭环、范式、底座、抓手、痛点、生态位。
- 不要「不仅 X 而且 Y」，不要硬凑三个一组，不要「从 X 到 Y」这种跨度不明的话。
- 写完自查一遍：这段读起来像 AI 写的吗，哪句是废话。
